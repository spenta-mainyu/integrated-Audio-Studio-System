سامانه جامع استودیوی صوت

تبدیل متن به گفتار، پیاده‌سازی صدا و ویرایش حرفه‌ای — همه لوکال، همه در یک فایل

کلید Google Gemini API

این کلید فقط در مرورگر شما (localStorage) ذخیره می‌شود و صرفاً برای بخش‌های متن‌به‌صوت و صوت‌به‌متن استفاده می‌گردد.

مدل‌های پیش‌فرض

مدل مورد استفاده در تب‌های متن‌به‌صوت و صوت‌به‌متن.

اگر پیام خطای «model … is not found» دیدید، مدل مذکور دیگر در دسترس نیست؛ از دکمهٔ زیر برای دیدن فهرست به‌روز مدل‌های فعال روی کلید خودتان استفاده کنید.

چگونه کلید رایگان Gemini API دریافت کنم؟

  1. وارد سایت Google AI Studio شوید.
  2. روی دکمه Get API key کلیک کرده و کلید خود را ایجاد کنید.
  3. آن را در فیلد بالا کپی و دکمه «ذخیره کلید» را بزنید.

پشتیبان‌گیری از تنظیمات

خروجی/ورودی گرفتن از کلید و تنظیمات به‌صورت فایل JSON.

استودیوی متن به صوت

متن انگلیسی خود را وارد کنید تا با صدای طبیعی Gemini تبدیل به فایل صوتی شود؛ برای دیالوگ می‌توانید دو گوینده با دو صدای جدا تعریف کنید.

هر خط را دقیقاً با نام گوینده (مطابق فیلدهای بالا) و دونقطه شروع کنید.
با دکمهٔ بالا می‌توانید صدای تولیدشده را مستقیماً به کتابخانهٔ تب «ویرایشگر صوتی» منتقل کنید.

صوت به متن (پیاده‌سازی)

یک فایل صوتی آپلود کنید تا متن آن استخراج شود.

متن استخراج‌شده اینجا نمایش داده می‌شود…
در صورت دریافت پیغام خطا هنگام استخراج متن، به تب «کلید API» بروید و در بخش «مدل STT (صوت به متن)» یک مدل دیگر را انتخاب کنید؛ سپس دوباره عملیات را امتحان کنید.

گفتگو با جمنای

برای گفتگوی آزاد با Gemini، وارد سایت اصلی آن شوید — رایگان و بدون نیاز به کلید API.

ویرایشگر صوتی حرفه‌ای چندتراکه

فایل صوتی بارگذاری کنید یا از کتابخانه استفاده کنید؛ برش، ادغام چند تراک، افکت فید، سکوت، نشانه‌گذاری و خروجی WAV / MP3 / M4A / WebM / Opus / OGG. صداهای تولیدشده در تب «متن به صوت» را می‌توانید مستقیماً به کتابخانهٔ این بخش اضافه کنید.
